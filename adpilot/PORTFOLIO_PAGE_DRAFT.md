**AdPilot — Agentic Campaign Optimization Copilot**

**Independent build · Synthetic campaigns · Agentic AI**

An LLM-powered advertising copilot that investigates campaign performance, identifies a small number of defensible optimization opportunities, and turns approved recommendations into safe, reversible changes in a simulated account.

**Customer problem:** Performance marketers spend time navigating dashboards, evaluating uncertain opportunities and manually updating campaigns.

**Product decision:** Build for fewer, higher-quality recommendations rather than an alert barrage. Agent chooses tools and explains evidence; deterministic software enforces data quality, campaign constraints and human approval.

**What I built:** Six LLM-callable campaign investigation tools, a Streamlit conversation interface, bounded budget-transfer previews, and an application-controlled sandbox execution with replay protection and audit logs.

**What I learned:** Historical CPA is not marginal CPA. Budget-limited status does not prove profitable additional inventory. Conversion maturity changes recommendation confidence. Deterministic policy and a real agent serve complementary roles.

**Evidence so far:** 17/17 offline unit tests and 15/15 synthetic deterministic policy evaluations passed. **Agentic model behavior, live deployment, advertiser value and performance lift remain unverified.**

**Next:** Capture real LLM tool traces, evaluate failures and abstentions, iterate, deploy a shareable app and publish measured improvements.
