# Husain Motiwala — Product Portfolio

Public portfolio of product leadership work in AI, search, advertising, ranking, and experimentation. The site includes an interactive intent-aware product discovery prototype and high-level professional case studies.

**Live site:** https://husain-motiwala-product-portfolio.husain-im13.chatgpt.site/

The site is a static HTML project. Open `dist/index.html` locally to browse it. The `dist/` directory contains the publishable pages. The live version is hosted separately at the link above.

Professional examples are intentionally limited to public-safe summaries. The prototype uses synthetic product data.

## AdPilot — evidence-driven iteration

[AdPilot case study](dist/adpilot/index.html) · [P0 → P0.5 → P1 design record](adpilot/README.md#why-p0--p05--p1-product-and-architecture-decision) · [Evaluation findings and P1 evaluation plan](adpilot/EVALUATION_AND_LEARNING.md)

The six-campaign synthetic prototype validated a local human-approved workflow (P0). P0.5 agent evaluations exposed both evidence-coverage problems and too many model/tool round trips; an account-wide snapshot improvement is prepared but not yet live-validated. A deterministic screen → evidence shortlist → Gemini deep dive architecture is the **proposed P1**, not a built or measured 1,000-campaign system. The live ChatGPT Site is hosted separately and does not automatically update when GitHub changes.
