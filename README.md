# Husain Motiwala — Product Portfolio

Public portfolio of product leadership work in AI, search, advertising, ranking, and experimentation. The site includes an interactive intent-aware product discovery prototype and high-level professional case studies.

**Live site:** https://husain-motiwala-product-portfolio.husain-im13.chatgpt.site/

The site is a static HTML project. Open `dist/index.html` locally to browse it. The `dist/` directory contains the publishable pages. The live version is hosted separately at the link above.

Professional examples are intentionally limited to public-safe summaries. The prototype uses synthetic product data.
